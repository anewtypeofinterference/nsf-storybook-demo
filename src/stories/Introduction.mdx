# NFS Designsystem

Storybook demo for the **NFS / NSF** design system, built with **Vite + React + TypeScript + Tailwind + shadcn/ui**.

Components are limited to shadcn instances that appear in the Figma Design canvas:

- Button, Card, Breadcrumb, Separator, Item
- Dialog, Tabs, Field, Input, Label, Select, Dropdown Menu, Sonner, Input Group

Pro Blocks stay deferred — see the empty **Blocks** sidebar section.
