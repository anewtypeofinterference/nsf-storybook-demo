# NFS Designsystem

Storybook demo for the **NFS / NSF** design system, built with **Vite + React + TypeScript + Tailwind + shadcn/ui**.

Components in this pass are limited to what appears in the initial Figma sketches:

- Button
- Card
- Breadcrumb
- Separator
- Item

Pro Blocks are intentionally deferred — see the empty **Blocks** sidebar section.
